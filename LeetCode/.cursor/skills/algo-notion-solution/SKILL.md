# 算法题 Notion 题解

## 触发条件

1. 用户提供了 **题目信息**（题号/题名/题意等）。
2. 消息中包含 **`题解`**。

## 参考格式

对齐用户 Notion 页：[LCR 139. 训练计划 I](https://app.notion.com/p/LCR-139-I-3dd5aa23e3dc80c8a04de35555a5b323)

## 执行步骤

1. 提取题号、题名、难度、标签；缺则推断并补「注」。
2. 搜索工作区同题 `.js` 作为代码来源；无则写可 AC 实现（默认 JavaScript）。
3. 按下方 **6 个二级模块** 及 **各模块内层次** 生成 Markdown，写入 `{题号}-{题名简写}-notion.md`。
4. 回复时给出路径 + 全文。

## 输出模板（6 个 `##` 模块）

```md
# {题号}. {题名}

难度: {🟢 / 🟡 / 🔴} ({一句注：题型定位})

标签: {标签1} {标签2} {标签3}

## 📝 题目描述

{只用 **大白话** 讲清这题在干什么：算什么、输入输出直觉、边界与示例数字（若有），2–4 段自然段即可}

{禁止在本节使用「题意 / 输入输出 / 约束」等小标题}

## 写作约束

- 页标题用一级 `#`；六个模块统一用 **二级 `##`**（📝 💡 🧠 📊 💻 ⚠️），不要用 `###` 做模块标题。
- **📝 题目描述** 仅大白话自然段，不写结构化小标题、不写链接。
- 其余模块内可用 **加粗小标题** + 列表/编号，避免文字墙。
- 「示例图解」必须含 **逐步推演** 有序列表。
- Notion：禁止 `\[ \]` / `\text{}`；优先 **Import → Markdown**。
- 语气讲解向、可复盘；不用「可能、猜测」。
